# v5 manifest cross-end fixture

Generated by `SyncContainer.SealManifest` (desktop, C#) for the web reader self-check.

- Space key: base64 of bytes 0x00..0x1F (`AAECAwQFBgcICQoLDA0ODxAREhMUFRYXGBkaGxwdHh8=`)
- Salt: bytes 0x40..0x5F (inside the 44-byte header, so the reader needs only the key)
- Plaintext: `v5-manifest.json`
- Container: `v5-manifest.b64` (base64 of 44B header + nonce/tag/ciphertext, raw GCM, no GZip)

Regenerate only when the v5 manifest container format changes on purpose; both the C# test and the Node self-check read this file.
