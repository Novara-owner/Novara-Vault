<h1 align="center">Novara</h1>

---

Novara 是一款面向 Windows 的**本地优先、注重隐私的个人知识管理工具**，基于 C# 与 WinUI 3 构建。它将备忘、路径备份、待办与便签、富文本日记整合进一个加密数据库——**全部数据只存在你自己的电脑上，无云端上传、无遥测、无账号注册**。

数据保存在 `%LocalAppData%\Novara\` 下的便携单文件数据库中，可选 **AES-256-GCM 认证加密** 保护，密码最长 64 位。无论是管理日常笔记、跟踪项目任务、保存常用路径、撰写私密日记，还是存储带连通性检测的 API Key，Novara 都能在一个快速、原生、稳定离线的应用里帮你搞定。

配合五种界面语言、浅色/深色/跟随系统主题、桌面便签、全局搜索、回收站与深度系统集成，Novara 致力于成为你最后一款笔记工具。

## 安全与隐私锁

可选密码保护，基于 **AES-256-GCM 认证加密**（3.0 起）。开启后，整个数据库在静止状态下加密——没有正确密码，任何备忘、路径、待办、日记都无法读取。密码支持 **6 至 64 位**，绝不明文存储（本地仅保存加盐 SHA-256 哈希）。无后门、无找回机制、无云端依赖——忘记密码的唯一出路是清空数据库重新开始。

GCM 提供**认证加密**：加密文件被篡改会被密码学标签立即发现，损坏或被修改的数据会被明确报告，而不是被静默误读。由 Novara 2.0（旧版 AES-CBC）创建的数据库，在首次解锁确认一次后即可无缝迁移到新格式——已有数据原地升级，不丢失任何内容。

安全机制还包括 **连续 5 次输错锁定 30 分钟**——计数与锁定状态跨重启持久化，杜绝暴力破解绕过。锁屏跟随系统主题、全屏遮挡应用、窗口失焦自动清空输入框，在共享环境下防止窥屏。

## 备忘管理

存放所有备忘的主页——Novara 的核心中枢。你可以把条目组织进自定义分组，星标或置顶重要条目以便快速访问，并通过右键菜单在分组间移动，按你的思路组织数据。

五种内置条目类型——**邮箱、账户、API Key、网站、自定义**——覆盖绝大多数场景：

- **邮箱**：地址 + 密码，可加备注
- **账户**：账号 + 密码，可加备注
- **API Key**：Key + 接口 URL + 模型 ID，可加备注
- **网站**：名称 + 网址，可加备注
- **自定义**：无限灵活的键值字段

星标与置顶条目置顶显示，每张卡片第二行展示关键信息，一眼识别。

### API Key 管理与连通性检测

在 AI 与 LLM 应用日益普及的今天，安全地管理 API Key 从未如此重要。Novara 将你的 Key 保存在加密数据库中——远离明文泄露与窥探——但存储只是第一步。

每个 API Key 条目都内置连通性检测：右键条目选择「检测连通性」，Novara 会以幂等、零费用的 `GET /v1/models` 请求探测端点。它先尝试 Bearer 认证；若服务器返回 401 或 403，则自动去掉 Bearer 重试，同时兼容 OpenAI 标准与国内厂商。

结果以清晰的视觉状态呈现：**探测中**（主题色）、**成功**（绿）、**鉴权失败**（红）、**无 models 接口**（黄）、**网络异常**（红）。高级配置——OpenAI 标准（Bearer）、国内兼容（无 Bearer）、原始 RAW（禁用检测）——仅在探测失败后出现。测试成功自动保存可用协议，失败绝不篡改已保存的配置。

## 路径备份

专门用于保存与管理常用文件/文件夹路径的页面。把重要位置——项目目录、配置文件、日志文件夹——存下来，一键复制路径，另一键在资源管理器中打开并高亮文件。

新建或编辑条目时，你既可以手动输入路径，也可以用内置的**文件/文件夹选择器**直接选取——杜绝手误，无需猜测。

### 实时路径有效性检测

路径会变；文件会被移动或删除。Novara 持续监控每一条已保存路径并给出即时视觉反馈：**绿色边框**表示路径存在，**红色边框**表示缺失或不可访问。

有效性检测在五种场景自动触发：新建/编辑条目时、30 分钟后台定时、应用启动时、空白区域全量检测、单卡右键检测。你永远一眼就知道保存的位置是否仍然有效。

## 任务面板

一个轻量的生产力看板，把待办、便签与定时提醒整合在一处——你高效完成事情的第二大脑。

### 待办卡片

每张待办卡由主待办与可选子待办组成：

- 子待办全部勾选 → 主待办自动勾选 → 卡片折叠节省空间
- 取消任一子待办 → 主待办同步取消 → 卡片展开
- 手动取消主待办 → 子待办保持不变，卡片展开
- 无子待办 → 不显示展开按钮；勾选主待办即完成卡片

所有勾选状态持久化到磁盘，重启不丢。

### 便签

适合不适用待办格式的快速、非结构化笔记。内容超过 240 字或含换行时显示展开按钮；展开后解除行数限制。展开/折叠状态持久化。

### 系统提醒

在面板空白处右键选择「添加提醒」，即可在桌面创建倒计时卡片。提醒以紧凑的悬浮卡片显示实时倒计时，到点响铃三声、红色脉冲闪烁后自动关闭——即使 Novara 主程序未运行也能工作。

## 富文本日记

基于 WebView2 的全功能富文本日记编辑器，把写日记变成愉悦的写作体验——私人日志、会议纪要或详细项目文档皆可胜任。

- **格式化工具**：加粗、斜体、下划线、字体颜色；悬浮胶囊工具栏无需滚动即可触达
- **图片插入**：直接粘贴或上传图片到编辑器；以 base64 编码存入数据库
- **HTML 导入**：从其他来源粘贴格式化内容；自动净化，移除脚本与危险属性
- **自动保存与数据安全**：离开或关闭应用时内容自动保留；阻止空白覆盖；HTML 在保存与加载时双重净化（严格白名单），让日记远离 XSS

## 全局搜索

在任何界面按下 **Ctrl+K** 打开全局搜索页，一键找到任何内容。备忘、路径、待办、便签、日记五类结果聚合在同一列表，按时间排序，命中关键词高亮。

点击结果直接跳转——Novara 自动切到对应页面、把目标卡片滚动到视野内，并以品牌色脉冲闪烁标记落点。冷启动重试机制保证即使在刚启动的应用里跳转也必定命中。

## 桌面便签

一键把任意便签卡发送到桌面。Novara 运行一个轻量独立进程（**StickNoteHost**），即使主程序关闭，桌面便签依然可见：

- **拖动与缩放**：解锁便签后可任意移动位置、从任意边缘调整大小
- **锁定置顶**：锁定便签固定位置、保持置顶，且不被 Win+D 隐藏
- **主题与语言同步**：便签即时跟随应用主题与语言
- **桌面编辑**：右键便签选择「编辑」，Novara 自动打开对应卡片的编辑弹窗
- **实时同步**：在 Novara 中编辑或删除卡片，桌面便签实时更新或移除

## 回收站

删除的卡片不会瞬间消失。Novara 将删除的条目移入**回收站**并支持**7 天自动清理**：删除内容在一周内可随时恢复，超过 7 天在下一次启动时永久删除。

回收站支持**恢复**（回到原页面）与**永久删除**（红色二次确认）、**清空回收站**，以及按时间倒序混合展示所有可恢复内容。已删除的桌面便签会同步从桌面移除，回收站数据不参与导出。

## 五语言界面

Novara 内置**五种完整界面语言**——简体中文、繁體中文、English、한국어、日本語——并提供「跟随系统」选项，自动匹配 Windows 系统语言。

切换无缝流畅：在设置中选择语言、确认后应用重启即全量翻译——每个页面、弹窗、菜单无一遗漏，绝无半吊子翻译。界面基于静态资源字典（无运行时 XAML 合并），零崩溃风险、即时查找。你的数据完全与语言无关：只有界面文本被翻译，备忘、待办、日记永远保持你书写时的原样。

## 主题系统

Novara 提供三种主题——**浅色、深色、跟随系统**——在设置中一键切换。每种颜色、边框、表面都经过多轮精调，两种模式下都呈现精致的质感：深色模式深邃舒适，适合夜间使用；浅色模式明快清爽，适合白天工作。

统一的按钮体系强化视觉层级：主操作使用品牌蓝并带平滑的悬停/按下反馈，次要操作使用描边"幽灵"样式，危险操作用红色——全应用每个弹窗保持一致。主题偏好跨重启持久保存。

## 数据导入与导出

你的数据应该随你自由、安全、无摩擦地迁移。Novara 提供完整的数据库备份与恢复：

- **导出**始终为带 MD5 完整性头的明文——可读、可检查、跨版本兼容，无专有格式、无供应商锁定
- **导入**执行严格校验：重复 ID 自动重建、空分区归一化、悬空引用清理；任一步失败，数据库安全回滚
- 加密数据库的导入与导出均需密码验证
- 为换新电脑导出时，路径备份**默认排除**（可勾选包含）——路径很难随迁移存活，从干净开始，而不是面对一片红色失效路径

## 启动、托盘与系统集成

Novara 适配你的工作方式：

- **开机自启**——登录时工作区即就绪
- **系统托盘模式**——让 Novara 在后台安静常驻；单击托盘图标显示/隐藏窗口
- **全局右键菜单**——在资源管理器中右键任意文件/文件夹即可添加到路径备份，或右键桌面直接打开 Novara
- **桌面提醒**——倒计时卡片在主程序关闭后依然工作

## 数据与隐私一览

- **本地优先**：一切只存在你的电脑上——无云、无遥测、无账号
- **认证加密**：AES-256-GCM + PBKDF2 密钥派生（10 万次迭代）
- **便携单文件**：`data.novadb` 承载全部七个分区；可选密码保护整个数据库
- **可恢复删除**：回收站给你一周时间，任何内容才真正消失
- **开放诚实的存储**：导出为带完整性校验的明文——你的数据永远不会被锁进读不懂的格式
