# 无障碍

[English](ACCESSIBILITY.md) · 简体中文

Novara 基于 WinUI 3 构建，天然获得 UI Automation（UIA）层、键盘导航与系统主题集成。本页记录应用为无障碍做了什么，以及代码遵循的约定。

## 键盘可达

- 所有界面均可键盘到达；Tab 与方向键移动焦点，Esc 关闭弹窗与菜单，Enter 确认。
- 全局快捷键：`Ctrl+K` 全局搜索、`Ctrl+T` 工具、`Ctrl+,` 设置、`Ctrl+Shift+Backspace` 回收站、`Ctrl+Shift+N` 快速捕获。快捷键在锁屏、欢迎页或文本输入持有焦点时抑制，绝不在错误语境触发。
- 弹窗结构一致（标题行、内容、底部动作行），主操作是真实按钮，读屏器直接播报焦点动作。

## 读屏器支持

- 全部控件为标准 WinUI 控件，自动暴露 UI Automation peer。
- **每个纯图标按钮都带 `AutomationProperties.Name`**（撰稿时共 145 个，由仓库守卫验证）。名称已本地化：与可见 UI 走同一五语言字典，读屏器以用户自己的语言播报「关闭」/ "Close" / 「閉じる」。
- 带文字的按钮经内容暴露标签，无需额外属性。

## 视觉无障碍

- 焦点视觉为 WinUI 默认系统焦点框——恒定绘制、从不抑制。
- 深浅主题跟随系统；品牌与危险强调色按主题定义并顾及对比度，类纸主题柔化强调色同时保持文字对比。
- 动效尊重应用的动画开关（设置 → 显示模式），对运动敏感的用户可关闭装饰性动效系统。

## 新代码约定

- 纯图标按钮必须带从字符串字典解析的 `AutomationProperties.Name`（`{x:Bind app:App.GetString('...')}`）；仓库静态检查套件中的守卫会在纯图标按钮未命名时使构建失败。
- 新交互元素必须保持键盘可达——主要动作不得只有指针手势。
- 新颜色必须以命名主题资源落地（逐主题对比度审查），不用内联字面量。

若遇到本页声称已覆盖的无障碍障碍，请提 issue（安全相关走 [SECURITY.zh-CN.md](../SECURITY.zh-CN.md) 的私密渠道）——精确描述焦点或播报在哪里出错，是修复它最快的方式。
